# Little Grimoire 👻

Little Grimoire is a small personal planner built with React.
It combines a habit tracker, daily planner, diary and dashboard in one cozy little grimoire.

## ✨ About

This project is being developed as part of my Software Engineering course at WBS CODING SCHOOL.

The goal is to build a React application that combines daily planning, habit tracking and diary entries while practicing React fundamentals such as components, state, props, hooks and localStorage.

## 🛠️ Tech

- React
- Vite
- JavaScript
- CSS
- localStorage
- DaisyUI

## 🚀 Run locally

```bash
npm install
npm run dev
```

## 📍 Status

🚧 Currently in development.

The project is being built incrementally, starting with the basic application structure and Habit Tracker before adding the Daily Planner, Diary and Dashboard functionality.
